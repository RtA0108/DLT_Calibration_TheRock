# 새 모델 추가 방법

새 3D 모델(OBJ)을 캘리브레이션 프로그램의 모델 목록에 넣는 방법입니다.
Unity 메뉴 **Tools > 캘리브레이션 > 새 모델 추가** 창에서 버튼 한 번으로 끝납니다.
창 위쪽의 **사용법** 버튼을 누르면 이 문서가 열립니다.

---

## 1. 준비물

| 항목 | 필수 | 설명 |
|---|---|---|
| OBJ 파일 | 필수 | 모델 파일. 어느 폴더에 있어도 됩니다 (도구가 프로젝트 안으로 복사). |
| 텍스처 이미지 | 선택 | MTL 파일이 OBJ 옆에 있으면 자동으로 찾습니다. MTL이 없으면 이미지를 직접 고르면 됩니다. |
| 4D 텍스처 폴더 | 선택 | 움직이는 텍스처로 쓸 이미지 시퀀스(프레임 이미지들)가 든 폴더 |

saliency 계산에는 이 PC의 Python 환경이 필요합니다.
- CfS-CNN: Windows `python` + `PythonScripts/bridge_cfs.py` + `PythonScripts/net-deployed.mat`
  - `net-deployed.mat`(학습된 네트워크, 약 370MB)은 GitHub 용량 제한 때문에 **이 저장소에 없습니다.** 따로 받아서 `DLTcalibration/PythonScripts/`에 넣어야 합니다.
- TexMesh: WSL의 `/home/minsu/TexMeshSaliency` 환경 (저장소 밖)

다른 PC에서는 이 환경이 없으면 saliency 계산이 실패합니다. 모델 등록 자체는 됩니다.
기본으로 들어 있는 TheRock은 saliency 결과가 이미 들어 있어서 Python 없이 바로 쓸 수 있습니다.

---

## 2. 순서

1. Unity 위쪽 메뉴에서 **Tools > 캘리브레이션 > 새 모델 추가**를 엽니다.
2. **OBJ 파일** 옆 **찾기**를 눌러 OBJ를 고릅니다.
   - id와 표시 이름이 파일 이름으로 자동으로 채워집니다.
   - 텍스처 칸 아래에 텍스처를 어떻게 찾았는지 나옵니다.

     | 안내 문구 | 뜻 |
     |---|---|
     | MTL(…)에 지정된 텍스처를 씁니다. | 정상. 따로 할 일 없음 |
     | MTL에 텍스처가 없어 이 이미지로 MTL을 만들어 연결합니다. | 같은 폴더에서 이미지를 찾았음. 맞는 이미지인지 확인 |
     | 텍스처 없음. … | 이미지를 못 찾았음. 텍스처가 있으면 **찾기**로 직접 고르기 |

3. **id**와 **표시 이름**을 확인합니다.
   - **id:** 영문, 숫자, `_`, `-`만 됩니다. 폴더 이름, 파일 이름, saliency 결과 파일 이름에 쓰입니다.
   - **표시 이름:** 모델 목록에 보이는 이름입니다. 한글도 됩니다.
4. (선택) 4D 텍스처가 있으면 **이미지 시퀀스 폴더**를 고릅니다.
   - **Resources로 복사** 켜기(기본): 프로젝트 안으로 복사합니다. 이걸 쓰세요.
   - 끄기: 원래 폴더를 그대로 참조합니다. 폴더를 옮기거나 지우면 재생되지 않습니다.
5. **saliency 계산**은 켜 둡니다(기본).
   - 끄면 플레이에서 이 모델을 처음 고를 때 자동으로 계산됩니다(그동안 Unity는 멈추지 않음).
6. **추가**를 누릅니다.
7. 아래 **결과**에 나온 메시지를 확인합니다 (3장 참고).
8. saliency 계산 중에는 진행 막대가 움직입니다. 보통 10~30초 걸리고, 큰 모델은 더 걸립니다. 그동안 에디터는 계속 쓸 수 있습니다.
   - **끝날 때까지 플레이를 시작하거나 스크립트를 고치지 마세요.** 계산은 끝까지 되지만 창이 결과를 확인하지 못합니다.
9. 플레이를 시작하고 오른쪽 모델 목록 **맨 아래**에서 새 모델을 고릅니다.

## 3. 결과 메시지 보는 법

정상이면 아래 메시지가 차례로 나옵니다(파란 아이콘).

| 메시지 | 뜻 |
|---|---|
| MTL 복사 / MTL이 없어 … 만들고 … 연결했습니다 | 텍스처 연결 준비 |
| OBJ 복사: … (버텍스 n개) | 프로젝트 안으로 복사 |
| 메쉬 Read/Write 켬 | 프로그램이 버텍스를 읽을 수 있게 설정 |
| Unity 메쉬 n개, 버텍스 n개, Read/Write 켜짐 | 실제로 불러와서 확인 |
| 텍스처가 재질에 연결됐습니다. | 텍스처 정상 |
| 라이브러리에 '…' 추가 | 모델 목록에 등록 |
| CfS-CNN / TexMesh: … (값 n개, OBJ 버텍스 n개) | saliency 결과. **두 숫자가 같아야 정상** |

노란색(경고)이나 빨간색(오류)이 나오면:

| 메시지 | 할 일 |
|---|---|
| 텍스처를 지정했지만 재질에 연결되지 않았습니다 | MTL 파일 내용을 확인하거나, 텍스처를 직접 골라 같은 id로 다시 추가 |
| MTL의 텍스처를 찾지 못했습니다: … | MTL이 가리키는 이미지가 없음. 이미지를 OBJ 옆에 두거나 직접 골라서 다시 추가 |
| 텍스처가 없습니다 | 텍스처 없는 모델이면 그대로 써도 됨 (흰색으로 보이고, TexMesh는 형상만으로 계산) |
| … 계산 실패. 콘솔의 Python 출력을 확인하세요 | Console 창의 `[Local(CfS)]`, `[WSL(Tex)]` 로그 확인. Python 환경 문제가 대부분 |
| 값 n개, OBJ 버텍스 m개 (숫자가 다름) | saliency와 버텍스가 어긋남. 같은 id로 다시 추가해 다시 계산해 보고, 그래도 다르면 OBJ 파일 확인 |
| 같은 이름의 saliency 결과가 이미 있어 그대로 쓰입니다 | 모델이 바뀌었으면 **saliency 계산**을 켜고 다시 추가 |
| id '…'는 이미 다른 모델에 쓰이고 있습니다 | 다른 id 쓰기 |

## 4. 도구가 만드는 파일

`<id>`는 창에서 정한 id입니다. 모두 `DLTcalibration/Assets/Resources/` 아래입니다.

| 위치 | 내용 |
|---|---|
| `Meshes/<id>/<id>.obj` | 모델 (원본에서 MTL 연결 줄만 바뀜) |
| `Meshes/<id>/<id>.obj.mtl` | 재질 (텍스처 연결) |
| `Meshes/<id>/<이미지>` | 텍스처 이미지 |
| `4D_Textures/<id>/` | 4D 텍스처 프레임 (복사했을 때) |
| `Result_CfS/<id>_saliency.txt` | CfS-CNN saliency |
| `Result_Tex/<id>_vertex_saliency.txt` | TexMesh saliency (추천점 계산에 우선 사용) |
| `DefaultLibrary.txt` | 모델 목록. 맨 아래에 항목이 추가됨 |

**git 주의:** 위 파일은 모두 git에 올라갑니다(OBJ, 텍스처 포함).
GitHub는 **파일 하나가 100MB를 넘으면** 받지 않으니, 큰 모델은 git에 올리기 전에 크기를 확인하세요.

## 5. 자주 하는 일

**모델 파일을 고쳐서 다시 넣기**
같은 OBJ와 같은 id로 다시 **추가**합니다. "이미 있습니다. 덮어쓸까요?"에서 **덮어쓰기**를 고르고, **saliency 계산**은 꼭 켜 둡니다. 목록 항목은 그대로 유지됩니다.

**4D 텍스처만 나중에 넣기**
`Assets/Resources/4D_Textures/<id>/` 폴더를 만들고 이미지를 넣으면 됩니다. 도구를 다시 쓸 필요가 없습니다.
- 재생 순서는 파일 이름순입니다. 숫자는 크기순이라 `frame_2`가 `frame_10`보다 먼저입니다.
- 속도는 기본 24fps입니다. 바꾸려면 `DefaultLibrary.txt`의 그 모델 항목에 `"animatedTextureFps": 30`처럼 적습니다.
- 실행 중 **P** 키로 재생/정지합니다.

**처음 방향이 이상할 때**
실행 중에는 오른쪽 회전 슬라이더로 돌립니다. 매번 같은 방향으로 시작하게 하려면 `DefaultLibrary.txt`의 항목에 `"initialRotation": {"x": -90, "y": 0, "z": 0}`처럼 적습니다.
크기는 불러올 때 프로젝터 화면에 맞게 자동으로 조절되므로 신경 쓰지 않아도 됩니다.

**선 패치에 선이 너무 적거나 많을 때**
선 패치의 모서리 기준 각도는 모델 모양을 보고 자동으로 정해집니다(콘솔의 `[Patch] 선 패치 모서리 기준` 로그).
바꾸려면 `DefaultLibrary.txt`의 항목에 `"patchCreaseAngle": 20`처럼 적습니다. 숫자가 작을수록 선이 많아집니다.

**saliency만 다시 계산하기**
플레이 중 그 모델을 고른 상태에서 **F5**를 누릅니다. 뒤에서 계산되고, 끝나면 추천점이 새 결과로 바뀝니다.

**모델 지우기**
도구에는 지우는 기능이 없습니다. 아래를 직접 지웁니다.
1. `DefaultLibrary.txt`에서 그 항목(`{ … }`과 앞의 쉼표)
2. `Meshes/<id>/` 폴더
3. `Result_CfS/<id>_saliency.txt`, `Result_Tex/<id>_vertex_saliency.txt`
4. `4D_Textures/<id>/` 폴더 (있으면)

지울 때는 Unity Project 창에서 지워야 `.meta` 파일도 같이 정리됩니다.

## 6. 도구 없이 직접 할 때 (참고)

도구가 하는 일은 아래와 같습니다. 직접 하려면 하나라도 빠지면 안 됩니다.

1. OBJ, MTL, 텍스처를 `Assets/Resources/Meshes/<id>/`에 넣고 OBJ 이름을 `<id>.obj`로 맞춥니다.
   - saliency 결과 파일 이름이 OBJ 이름을 따릅니다.
2. OBJ에 `mtllib <MTL 파일 이름>` 줄이 있고, 첫 `f` 줄 앞에 `usemtl <재질 이름>` 줄이 있어야 합니다.
   - 둘 중 하나라도 없으면 Unity가 텍스처를 연결하지 않습니다.
3. MTL의 `map_Kd`가 같은 폴더의 이미지 파일 이름을 가리켜야 합니다.
4. Unity에서 OBJ를 선택하고 Inspector의 Model 탭에서 **Read/Write**를 켜고 **Apply**를 누릅니다.
   - 꺼져 있으면 버텍스 구가 생기지 않고 추천도 안 됩니다.
5. `DefaultLibrary.txt` 맨 아래에 항목을 추가합니다.
   ```json
   {
       "id": "<id>",
       "displayName": "<표시 이름>",
       "isBuiltIn": true,
       "meshPath": "Meshes/<id>/<id>",
       "cfsDataPath": "",
       "texDataPath": ""
   }
   ```
6. saliency는 플레이에서 처음 고를 때 자동으로 계산됩니다.
