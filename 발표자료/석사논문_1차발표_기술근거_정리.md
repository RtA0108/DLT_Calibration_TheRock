### 2-2. 기하 근거와 다중 시점 의미 근거를 결합하는 방법

각 observation r의 face별 hit를 h_rf, visibility를 v_rf, observation quality를 q_r라 할 때 후보 S의 적합도는 다음이다.

`fit_r(S) = q_r × [Σ(f∈S) h_rf] / [Σ_f h_rf + Σ(f∈S) v_rf − Σ(f∈S) h_rf]`

후보가 그 view의 visible area 5% 미만이면 fit은 0이다. 서로 다른 시점 r,s의 일관성은 `pair_fit_rs(S) = min(fit_r(S), fit_s(S)) × soft_overlap(r,s)`로 두고, 후보 집합 C의 목적함수는 `F(C) = Σ_(r,s) w_rs × max_(U∈single_or_pair_union(C)) pair_fit_rs(U)`다. 같은 source 내부에서만 pair를 만들고, `1/sqrt(deg(r)deg(s))`로 degree correction한 뒤 source별 정규화한다. unprompted와 prompted source가 모두 있으면 각각 0.5, 하나만 있으면 1.0이다. 관측되지 않은 face는 negative로 취급하지 않는다.

기하 근거는 PartField feature/hierarchy와 mesh adjacency로 **가능한 표면 단위와 경계**를 제공하고, 의미 근거는 여러 view에서 어느 후보가 공통 term/mask를 설명하는지 **선택 점수**를 제공한다. DINO/SAM mask를 그대로 3D ground truth로 선언하지 않는다.

### ★2-3. 집합 연산과 “oracle 선택 용량”

E86의 문법은 정확히 다음 세 종류다.

- `SINGLE(A) = A`
- `UNION(A,B) = A ∪ B` — unordered pair
- `DIFFERENCE(A,B) = A − B` — ordered pair

표현 하나는 catalog entry를 최대 2개 참조하고 Boolean operation은 최대 1회다. target mask T와 표현 mask M에 대해 면적 가중으로 `hit = area(M ∩ T)`, `selected = area(M)`, `target = area(T)`를 계산하고 `IoU(M,T) = hit / (target + selected − hit)`로 점수를 낸다. 각 target/B에서 가능한 모든 문법 표현 중 최대 IoU를 고르는 값이 **oracle expression capacity**다.

따라서 oracle은 “시스템이 target을 모르는 상태에서 자동으로 맞는 식을 골랐다”는 뜻이 아니다. 평가 시 reference target을 보고 가능한 최선의 표현을 사후 선택한 **상한/표현력**이다. E86은 자동 semantic segmentation accuracy나 사용자 선택 정확도를 증명하지 않는다. `small target`은 `target_area < 0.01 × annotated_total_area`로 정의한다. 통계는 10,000회 mesh-cluster bootstrap, seed 8601이다.

### 2-4. soft membership, core / transition band / halo 계산 방법

E85/E86 oracle 평가는 hard Boolean expression을 사용한다. 아래 soft field는 후속 저작/표면 합성 단계의 구현이며 E86 점수와 혼동하면 안 된다.

- feature-soft membership: 각 face와 region의 448-D cosine 유사도를 temperature **0.055** softmax로 바꾸고 semantic affinity 배수 `0.72 + 0.28 × semantic_affinity`를 곱한다.
- 초기 field: `field_0 = 0.78 × hard_onehot + 0.22 × proposal_soft`.
- 5회 graph diffusion: neighbor weight는 `exp[-3.5 × (boundary_i + boundary_j)]`; 매 iteration에서 `field ← 0.78×field + 0.22×neighbor`, 이어 `field ← 0.68×field + 0.32×hard`, 마지막에 normalize한다.
- core: 내부 topological depth × semantic probability × confidence × certainty의 곱으로 설명되어 있다. 각 항의 exact normalization식은 문서/코드에서 하나의 frozen 공식으로 **확인 불가**다.
- transition band: hard boundary 안쪽으로 face-adjacency **3 step**까지 decay한다.
- halo: hard region 바깥 **12 adjacency step**까지 `exp(−d/3.6)`로 감쇠하고 semantic probability/certainty로 약화한다.
- 최종 적용 field: `max(core, 0.68 × transition_band, halo)`.

### ★3-2. 역할(Source, Path, Barrier, Reservoir, Modifier, Sink)을 정하는 방법

현재 pipeline의 최초 역할은 **자동 geometry heuristic 제안**이고 최종 역할은 **사람이 편집·승인**한다. 학습된 기능 인식이나 의미 ground truth가 아니다.

### ★6-2. 다중 시점 fusion 가중치 식

v30의 8-view rest/state bake는 먼저 camera-facing과 화면 중심 신뢰도를 사용한다.

`r² = ((sx − W/2)² + (sy − H/2)²) / (W/2)²`

`w0 = visible × max(n·v, 0)^4 × exp(−0.34 × r²)`

`n·v ≤ 0.02`인 표본은 제외한다. 1차 rest 평균과 각 view rest의 RGB residual 크기 `e`를 구한 뒤 Huber형 신뢰도를 적용한다.

### 9-2. 각 논문과 본 연구의 관련성

| 선행연구 | 본 연구에서의 위치 |
|---|---|
| PartField | category-agnostic continuous 3D feature와 hierarchy를 MSR proposal의 주 입력으로 사용한다. |
| PartSLIP | 2D image-language semantics를 3D part로 lift하는 계열의 비교·배경이다. |
| Grounding DINO | text prompt로 view별 object/part box를 제안해 SAM2 prompt로 전달한다. |
| SAM2 | box/point를 받아 multi-view mask를 만들고 E222 owner confidence로 lift한다. |
| FLUX.2 | 고정 view와 owner mask를 조건으로 local peak appearance 후보를 만든다. |
| LTX-Video | keyframe-guided local temporal RGB, motion, occlusion 변화의 backend다. |
| Tex4D | 시간과 다면 일관성을 함께 다루는 4D texturing 문제 설정과 비교된다. |
| PixTex | pixel-space synchronized multi-view texture 생성의 최신 비교 대상이다. |
| TexPainter | 독립 view 결과를 그대로 쓰지 않고 multi-view consistency를 강제해야 한다는 근거다. |
| Text2Tex | view-conditioned iterative texturing의 대표 baseline/관련연구다. |
| MVPaint | synchronized multi-view diffusion, UV refinement, seam smoothing의 필요성을 뒷받침한다. |
| SuperFlux | vibrato를 억제한 onset detector 설계의 근거다. 본 코드는 전체 논문 재현이 아니므로 SuperFlux-like로 표현한다. |
| HPSS | harmonic/percussive median filtering으로 audio control lane을 분리하는 근거다. |
| Shader Lamps | 실제 물체 appearance를 projection으로 바꾸는 projection mapping의 고전적 기반이다. |
| Liu et al. semantic placement | 물체의 의미 있는 위치에 콘텐츠를 배치하는 authoring 문제와 직접 연결된다. |
