## 0. 결론 요약

현재 v18은 연구의 기술 흐름과 실제 결과를 이전 버전보다 훨씬 잘 보여 준다. 특히 캥거루 MSR 그림, MSRG 역할 그림, 30초 오디오 사건 타임라인, 실물 프로젝션 영상은 발표의 핵심 시각 자료로 쓸 수 있다.

다만 그대로 발표하면 다음 세 가지가 질문에서 가장 먼저 공격받을 수 있다.

1. **PartField 기반 E85/E86과 실제 캥거루·The Rock 통합 실행의 `geometry_fallback`을 한 파이프라인처럼 읽히게 한 점**
2. **슬라이드 13의 최신 자동 역할 제안(v57)과 슬라이드 36의 이전 기하 점수식이 서로 다른 점**
3. **자동 제안, 편집기 구현, 사용자 승인 완료를 일부 문구가 구분하지 않는 점**

실험의 결론은 전부 같은 강도로 성립하지 않는다.

- **제한된 정량 결론이 충분히 성립:** E86의 bounded expression grammar에 대한 oracle 표현 용량 향상
- **통제된 구현 기여가 성립:** E56의 역할 기반 다차원 반응, E227의 soft multiview fusion, E226/E230의 배타 소유권·handoff·원속도 결합
- **내부 sanity check 또는 통합 사례:** E231의 정렬 진단, E237의 현재 30초 결과
- **아직 결론을 내리면 안 되는 항목:** 지각적 우수성, 저작 시간 단축, 자동 역할의 의미 정확도, 임의 메시·음악 일반화, 실제 프로젝션 정량 정확도

따라서 현재 실험들은 **“구성 요소가 의도한 기술적 기능을 수행한다”는 석사논문 중간발표 결론에는 충분히 합당**하다. 그러나 **“사용자가 더 좋다고 느낀다”, “저작이 쉬워졌다”, “임의 메시와 음악에 일반화된다”, “실제 프로젝션 정확도가 검증됐다”는 최종 결론에는 아직 부족**하다.

### 1-2. 슬라이드 13과 36의 역할 점수 불일치 수정

### 1-6. 슬라이드 16의 “배타 소유권”을 풀어 쓰고 5번 항목 이동

슬라이드 16의 `배타 소유권(exclusive ownership)`은 **UV texture의 한 점(texel)에 여러 사건 효과를 동시에 덧쓰지 않도록, 최종 합성 단계에서 그 점을 담당할 사건 영역을 하나만 정하는 규칙**이다. 예를 들어 눈 사건과 전면 사건이 시간상 동시에 진행되어도 눈 영역의 texel에는 눈 사건만 적용하고 전면 사건은 그 점을 건드리지 않는다. 이 규칙으로 중복 합성, 색의 과도한 누적, 보호 부위 침범을 막는다.

MSR의 `core / band / halo`가 soft field라는 설명과 모순되는 것은 아니다. 영역 경계의 적용 강도는 soft alpha로 완만하게 만들 수 있지만, 서로 다른 사건이 겹치는 위치에서는 최종 담당 owner를 하나만 선택한다.

`배타 소유권`만 적으면 발표 청중이 의미를 알기 어렵다. 슬라이드에서는 다음처럼 바꾸는 편이 낫다.

> **영역별 충돌 방지**  
> 각 UV 점에는 한 사건만 적용한다. 여러 사건이 동시에 진행돼도 같은 표면을 중복해서 바꾸지 않는다.

슬라이드 제목도 `④ UV 통합과 배타 소유권`보다 다음이 명확하다.

> ④ 생성 영상을 UV 표면에 통합

현재 5번 항목인 `원속도 이어 붙이기`는 기술적으로 의미가 있지만, UV 공간 통합의 설명은 아니다. 이는 사건 영상을 시간축에서 조합하는 규칙이므로 슬라이드 16에서 제거하고 E230/E231/E237의 시간 편성 또는 검증 슬라이드로 이동한다.

권장 슬라이드 16 구성은 네 항목이다.

1. **표면 위치 계산:** face ID와 barycentric coordinate로 화면 픽셀과 UV texel을 대응시킨다.
2. **보이는 시점만 사용:** 해당 면이 실제로 보이는 시점의 색만 가져온다.
3. **다중 시점 통합:** 정면성, 화면 신뢰도, 시점 간 색 차이를 이용해 변화량을 가중 평균한다.
4. **영역별 충돌 방지:** 한 UV 점에는 한 사건만 적용해 동시 사건의 중복과 보호 영역 침범을 막는다.

`원속도 이어 붙이기`를 다른 슬라이드로 옮길 때의 권장 문구:

> 각 사건 영상은 늘이거나 반복하지 않고 원래 속도로 한 번만 재생한다.

발표자가 대본을 읽기 어렵다는 점을 고려해 텍스트를 모두 없앨 필요는 없다. 다만 본문 12–15pt 글자는 프로젝터에서 작다. **본문의 핵심 문장은 18pt 이상**, 상세 근거는 부록이나 발표자 노트로 보내는 편이 안전하다. 한 슬라이드에는 “주장 1문장 + 근거 2–3개”만 남기는 구성이 적합하다.

## 3. Experiment 비교와 결론의 타당성

### 3-1. 판정 기준

- **A:** 비교군과 측정 방법이 주장에 직접 대응하고, 제한된 결론을 지지함
- **B:** 내부 통제와 기술 게이트는 타당하지만 표본·범위가 좁음
- **C:** 파일럿·시연·사례 연구로는 유효하나 비교 결론을 내리기 어려움
- **FAIL/HOLD:** 사전 기준을 충족하지 못했거나 최종 결론이 유보됨

### 3-2. 실험별 판정

### 3-3. 핵심 실험별 상세 해석

#### E86: 현재 가장 강한 정량 결과

E86은 16개 미사용 메시, 164개 참조 부위, 네 후보 예산에서 같은 bounded expression grammar를 비교한다. primary zoom signed의 mean IoU는 `0.5019628140`, raw는 `0.4584288104`, unprompted는 `0.4853069080`이다. primary-minus-raw는 `+4.3534%p`, 95% CI `[+2.0086,+7.2207]`; primary-minus-unprompted는 `+1.6656%p`, 95% CI `[+0.7818,+2.6324]`다.

이 비교는 **“후보를 조합해 참조 부위를 표현할 수 있는 최대 용량”**이라는 질문에는 합당하다. 다만 ground truth로 최적 표현을 선택한 oracle 평가이므로, 자동 selector의 정확도나 사용자가 실제로 더 빨리 작업한다는 결론으로 확장하면 안 된다. small part 개별 실패도 남아 있다.

근거: `agentic_audio_projection_mapping/docs/experiment86_final_judgment.md`

#### E56: 역할 그래프의 기능 격리에는 합당, 일반화에는 부족

E56은 같은 오디오, 같은 중립 재질, 같은 display scale, 같은 source anchor를 고정하고 Global, Isotropic, Hard MSR, Soft MSR, Full MSRG를 비교했다. Full MSRG effective rank는 두 개발 사례에서 `3.58`, `2.24`였고 Global과 Soft MSR은 `1.00`이었다.

따라서 **역할·전달을 추가했을 때 서로 다른 지역 시간 응답이 생긴다**는 기능 격리 결론은 타당하다. 하지만 두 메시가 모두 개발 중 사용됐고 정책도 authored이므로 held-out 일반화나 자동 역할의 의미 정확도, 미적 우수성을 결론 내릴 수 없다.

근거: `agentic_audio_projection_mapping/docs/experiment56_final_judgment.md`

#### E227: 공학적 ablation으로는 설득력 있음

동일한 생성 프레임에서 hard single-view selection과 soft multiview fusion을 비교했다. hard cross-face residual gradient `2.6017`에서 soft `2.3629`로 `9.18%` 감소했고, protected texel change는 `0`, exact duplicate adjacent pair는 `0`이다.

이 비교는 다른 변수를 고정한 ablation이므로 합당하다. 단일 객체·단일 사건 결과이므로 “항상 9.18% 개선”이나 지각적으로 seam이 사라졌다는 일반화는 피해야 한다.

근거: `agentic_audio_projection_mapping/docs/experiment227_final_judgment.md`

#### E231: 좋은 내부 대조군이지만 지각 평가를 대신하지 못함

E231은 영상은 같고 오디오만 7초 순환 이동한 대조군을 둬 음악–사건 정렬만 분리했다. 설계된 trigger hit는 aligned `5/5`, shifted `0/5`, 평균 role-conditioned start score는 `0.8380` 대 `0.2104`다.

대조 구조 자체는 합당하다. 하지만 사건 시작점을 같은 특징과 규칙으로 선택했기 때문에 aligned가 해당 내부 점수에서 높게 나오는 것은 상당 부분 설계상 기대되는 결과다. 사건 수도 5개이고 이동량도 +7초 하나뿐이다. 따라서 **파이프라인 sanity check**로는 충분하지만, 사람이 aligned를 선호한다는 결론에는 paired perceptual evaluation이 필요하다.

근거: `agentic_audio_projection_mapping/docs/experiment231_final_judgment.md`

#### E237: 최신 성과이지만 실험보다 case study

E237은 새 전면·눈·코 표현과 기존 귀·입·후면 사건을 한 곡 안에서 선택·중첩한 최신 결과다. `1024×1024`, 24fps, 720프레임, 30초이며 최대 동시 사건 수는 2다. 약한 후보를 건너뛰고 동시 시작을 허용한다는 현재 planner의 동작을 잘 보여 준다.

하지만 matched baseline, 여러 곡, 여러 메시, blind user comparison이 없다. 발표에서는 “현재 통합 결과”로 보여 주고, 그 자체를 RQ 전체의 정량 결론으로 사용하지 않는 것이 안전하다.

근거: `agentic_audio_projection_mapping/docs/experiment237_final_judgment.md`

## 4. 발표에서 사용할 결론의 강도

### 4-1. 검증 완료로 말해도 되는 것

1. 제한된 연산 예산에서 MSR 후보 문법의 oracle 표현 용량이 raw·unprompted control보다 평균적으로 높았다(E86).
2. 고정 authored audio-to-role policy에서 Full MSRG가 두 개발 메시에서 단일 전역 변조와 다른 region-specific response를 만들었다(E56).
3. continuous UV ownership, exclusive owner, real-frame handoff, soft multiview fusion이 각각 경계·침범·중복·cross-face gradient에 대한 기술 게이트를 통과했다(E222/E226/E227/E230).
4. 실제 음악 특징을 이용해 사건 시작·공백·중첩을 구성하고 30초 UV video texture로 재생하는 통합 사례를 만들었다(E231/E237).

### 4-2. 파일럿 또는 시연으로만 말해야 하는 것

1. E198/E201 갈비 사건은 국소 사건 표현과 다각도 출력 사례다.
2. E231의 `0.838 vs 0.210`, `5/5 vs 0/5`는 내부 정렬 진단이다.
3. E237은 현재 시스템의 통합 case study다.
4. 실제 projector 영상은 정성적 물리 적용 확인이다.

### 4-3. 앞으로 검증해야 하는 것

1. **지각 평가:** aligned / shifted / silent 또는 full / no-role 조건의 paired comparison
2. **저작 평가:** 수동 workflow 대비 작업 시간, 수정 횟수, 최종 수용률
3. **일반화 평가:** 개발에 사용하지 않은 여러 메시와 여러 음악에서 동일 정책 검사
4. **자동 역할 평가:** 사람이 지정한 역할 또는 task outcome과 자동 제안의 일치도
5. **실제 투사 평가:** projector-camera 보정 후 mm 또는 pixel reprojection error, 표면 경계 정합 오차

이 다섯 항목은 슬라이드 25–27에서 **완료 결과와 분리된 평가 계획**으로 표시해야 한다.

## 5. 추천 발표 서사

발표의 핵심 문장은 다음처럼 정리하는 것이 가장 방어적이고 명확하다.

> 본 연구는 의미 있는 표면 영역을 제안·편집 가능한 MSR로 표현하고, 이를 역할 그래프 MSRG로 연결해 오디오 사건을 공간적으로 배치하며, 생성 결과를 canonical UV video texture로 통합하는 저작 파이프라인을 제안한다. 현재까지 영역 표현 용량과 역할 기반 반응, UV 통합의 기술 게이트를 검증했고, 한 메시·한 음악의 30초 통합 결과와 실제 투사 사례를 확보했다. 지각적 우수성, 저작 효율, 일반화, 실제 보정 정확도는 다음 평가 단계다.

이 문장은 현재 근거보다 강하게 주장하지 않으면서도, 이미 구현하고 검증한 기여를 충분히 드러낸다.
