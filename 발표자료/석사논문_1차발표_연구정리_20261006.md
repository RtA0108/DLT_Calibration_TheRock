# 석사논문 1차 발표용 연구 정리 — E237 및 Unity 실물 테스트 준비까지

작성일: 2026년 10월 6일  
현재 기준 결과: Experiment 237  
Unity 통합·소프트웨어 검증: Experiment 238

## 1. 연구를 한 문장으로 설명하면

사용자 프롬프트, 오디오와 고정 3D 메시를 입력으로 받아, 물체의 의미 있는 표면 부위마다 서로 다른 생성형 사건을 만들고 음악 구조에 따라 사건의 종류·시작·중첩을 결정한 뒤, 고정 메시의 video texture로 변환해 프로젝션 매핑에 사용하는 연구다.

이 연구의 목표는 음악 위에 파형·이퀄라이저·전면 플래시를 얹는 것이 아니다. 물체의 눈, 코, 입, 귀, 전면, 후면처럼 의미와 형상이 다른 표면이 서로 다른 사건을 갖고, 음악이 그 사건의 시간적 편성을 결정하도록 만드는 것이 핵심이다.

## 2. 현재 발표에서 주장할 수 있는 범위

현재 프로토타입은 하나의 고정 TheRock 메시와 하나의 30초 음악에서 다음을 구현하고 검증했다.

- 원래 호두나무 기본 텍스처와 메시 geometry·topology·silhouette 유지
- 눈·코·입·귀·전면·후면에 대응하는 연속 MSR과 배타 owner 사용
- pretrained image/video generation으로 국소 구조 사건 생성
- 음악 분석값으로 사건 종류, 시작 시점, 빈 구간, 자연 중첩과 동시 시작 결정
- source frame을 원속도로 소비하고 전체 화면 dissolve 없이 UV video texture 합성
- 다각도 3D 렌더와 WebGL viewer 검증
- Unity DLT calibration 프로젝트에 E237 영상·오디오를 연결하고 Windows Player 재생 검증

현재 결과는 `고정 메시에서 동작하는 audio-conditioned MSR event prototype`이다. 임의 메시 일반화, 임의 오디오에서의 완전 자동 생성, raw-audio latent 기반 생성, 실제 프로젝터 정밀도와 완전한 agentic loop까지 완료됐다는 뜻은 아니다.

## 3. 입력 구조

### 3.1 목표 입력 구조

사용자가 이해해야 하는 외부 입력과 시스템 내부에서 파생되는 입력을 구분하면 다음과 같다.

| 구분 | 항목 | 역할 |
|---|---|---|
| 사용자 입력 | 고정 mesh | 물체 형상, UV 또는 UV로 변환할 표면 기준 |
| 사용자 입력 | 사용자/style prompt | 원하는 재질, 분위기, 사건 문법과 금지 조건 |
| 사용자 입력 | audio file | 시간 구조와 사건 편성의 근거 |
| 파생 문맥 | mesh 특징 설명 | 정면·후면, 눈·코·입·귀, seam과 곡률 등 생성 prompt의 물체 문맥 |
| 생성·선택 결과 | 기본 texture | 사건 전 상태의 물체 전체 재질 |
| 파생 공간 정보 | MSR와 owner | 사건이 시작·진행할 영역과 영역 간 충돌 방지 |
| 파생 시간 정보 | audio controls | onset, attack, brightness, bass, novelty, section, multi-scale 상태 |
| 생성 결과 | 지역별 temporal event source | 각 MSR에서 일어나는 시간 RGB 변화 |

### 3.2 E237에서 실제 사용한 입력

- mesh: E95 계열 TheRock 고정 메시
- 사용자 의도: 나무 기본 텍스처를 유지하고, 여러 부위의 구조 사건이 음악에 따라 발생·중첩되게 함
- 기본 texture: E209 R5 walnut + amber resin UV
- MSR/owner: rear/front/eye/nose/mouth/ear 6개 배타 owner와 연속 alpha
- audio: `OpenEyeSignal_030.wav`, 30초, 48 kHz stereo
- 새 생성 사건: 전면, 눈, 코
- 검수 후 유지한 사건: 귀, 입, 후면

E237은 모든 사건 영상을 한 번에 새로 만든 결과가 아니다. 사용자 피드백으로 다시 만들어야 했던 전면·눈·코는 새로 생성했고, 이미 상대적으로 안정적이었던 귀·입·후면은 기존 검수 source를 유지했다.

### 3.3 owner의 의미

`owner`는 사용자가 별도로 준비하는 데이터가 아니다. MSR과 UV 표면 정보에서 파생되는 내부 충돌 방지 표현이다.

- 각 UV texel은 최대 하나의 owner에 속한다.
- 서로 다른 owner의 사건은 같은 시간에 진행될 수 있다.
- 같은 texel을 두 사건이 동시에 덮지 않으므로 눈 사건이 코나 귀를 침범하는 문제를 막는다.
- owner는 어디를 바꿀 수 있는지를 제한하고, 연속 MSR alpha는 경계를 부드럽게 만든다.

현재 owner는 각 부위당 하나의 비가역 상태 전환 source만 갖는다. 따라서 E237에서는 같은 owner 사건을 반복하지 않는다. 반복·복원·재발을 허용하려면 양방향 또는 순환 가능한 사건 source가 추가로 필요하다.

## 4. 현재 파이프라인

```text
고정 mesh + 사용자 prompt + audio file
        │
        ├─ mesh/다중시점 분석 ─> MSR, 연속 alpha, 배타 owner
        ├─ prompt 확장 ────────> 물체·재질·부위·금지 조건
        └─ 계층적 audio 분석 ──> micro/meso/macro controls
                                      │
기본 texture 생성·선정 ───────────────┤
                                      ▼
부위별 정적 peak 후보 생성 -> 고정 3D 다각도 gate
                                      │
                                      ▼
부위별 temporal RGB 생성 -> UV 등록 -> 보호 영역 검사
                                      │
audio trigger + 사건별 정규화 점수 ──┤
                                      ▼
사건 종류·시작·중첩·빈 구간 계획
                                      │
                                      ▼
30초 fixed-mesh UV video + audio mux
                                      │
                 ┌────────────────────┴────────────────────┐
                 ▼                                         ▼
       WebGL 3D viewer·QA                         Unity DLT calibration
                                                           │
                                                           ▼
                                          실제 projector/실물 검증(다음 단계)
```

### 4.1 계층적 오디오 분석

- micro: onset, percussive attack, 순간 변화
- meso: brightness, air, micro detail, harmonic sustain, density
- macro: section novelty, reorientation, reservoir, transport

오디오 특징은 사건별 의미와 연결된다. 예를 들어 후면 사건은 bass·reservoir·section macro에, 귀는 micro detail·noisiness·attack에, 전면은 reorientation·slow novelty에 더 큰 가중치를 둔다.

각 사건의 raw score를 그 사건이 30초 전체에서 보인 분포의 empirical percentile로 정규화한다. 사건마다 score 범위가 다른 문제를 줄이고, 임계값을 넘지 못하면 강한 onset이 있어도 아무 사건을 시작하지 않는다.

### 4.2 생성과 표면 등록

1. FLUX 계열 정적 후보로 사건의 peak 외형을 먼저 탐색한다.
2. 후보를 고정 메시의 정면·사면·측면·후면에 투영해 UI 모양, 검은 구멍, 날개·핀, 패치 경계 같은 실패를 제거한다.
3. 선택한 peak와 중간 상태를 LTX에 조건으로 주어 temporal RGB를 생성한다.
4. 생성 RGB를 원본 geometry를 바꾸지 않고 UV에 등록한다.
5. owner 바깥과 보호 영역의 변화량이 0인지 검사한다.
6. source frame을 반복·역재생하지 않고 원래 24 fps 순서로 사용한다.

E237에서는 LTX가 raw audio latent를 직접 받지 않았다. 분석된 오디오 특징이 사건 선택, 시간 편성과 전면·눈·코 prompt의 의미 조건으로 들어갔다. 따라서 정확한 표현은 `audio-conditioned planning and prompt semantics`이며 `end-to-end raw-audio-to-video generation`은 아니다.

### 6.3 사용자 관찰과 현재 미적 판단

- 음악에 맞춰 사건이 등장하고 서로 다른 부위가 동시에 반응하는 구조는 유효하다.
- 과거의 좋은 귀 사건은 유지됐다. 직전 실험에서 귀를 제외했던 것은 귀 표현 전체의 기각이 아니라 새로 만든 귀 표현에 대한 피드백 범위 오해였다.
- 전면은 E236보다 넓지만 밝고 수평적인 외피 판이 강해 기계적 인상이 남는다.
- 눈은 사건 자체의 가시성이 좋아졌지만 기괴하게 읽힐 가능성이 있다.
- 코는 날개형 temporal hallucination을 피한 대신 가장 약한 사건이다.
- 입은 전면 크기에서 변화가 작게 읽힐 수 있다.
- 단순 dissolve는 주된 표현 문법으로 부적합하다. 구조가 열리고 내부가 드러나며 완료 상태가 남는 캥거루 갈비 개방 계열의 문법이 더 적합하다.

## 7. 현재 연구의 잠정 기여

### 7.1 Meaningful Surface Region 기반 공간 제어

삼각형 전체나 화면의 사각형이 아니라 다중시점 관측을 UV texel로 융합한 연속 MSR를 사용한다. 사건은 실제 눈·귀·코·입의 표면에서 시작하고 owner가 충돌을 막는다.

### 7.2 역할 조건 오디오–표면 사건 편성

하나의 amplitude를 모든 시각 요소에 복사하지 않고, 사건 종류마다 다른 audio descriptor 조합을 사용한다. 사건을 강제로 모두 재생하지 않고 빈 구간과 동시 사건을 허용한다.

### 7.3 생성 모델과 결정적 표면 제약의 결합

생성 모델은 사건 RGB와 시간 변화를 만들고, 결정적 단계는 mask, owner, UV 등록, 합성, QA를 담당한다. 학습이나 fine-tuning 없이 pretrained inference만 사용한다.

### 7.4 검증 가능한 저작 파이프라인

prompt, seed, source, owner, audio score, 선택 시간, 실패 후보와 QA를 저장한다. 사람이 미적 판단을 하되 어떤 입력과 근거로 결과가 만들어졌는지 다시 추적할 수 있다.

이 항목들은 현재 `잠정 기여`다. 논문 기여로 확정하려면 baseline과 ablation, 사용자 평가, 다른 mesh/audio 실험이 추가돼야 한다.

## 8. 부족한 부분

### 8.1 표현 품질

- 전면: 표면 전체와 연결되지만 판·수평 층이 강하다.
- 눈: 검은 공동은 제거했으나 표정처럼 읽히는 기괴함이 남는다.
- 코: 구조적 가독성이 약하다.
- 입: 전체 물체 크기에서 사건이 작다.
- 부위마다 생성 강도와 시간 길이가 달라 한 영상 안에서 시각적 균형이 일정하지 않다.

### 8.2 사건 vocabulary

- 현재는 owner당 하나의 비가역 사건 source뿐이다.
- 같은 부위의 반복, 회복, 변주, 질문–응답 구조가 없다.
- 일부 source는 과거 검수 자산을 재사용하므로 매 오디오마다 모든 사건이 새로 생성되는 구조가 아니다.
- 생성 후보가 투사 표면보다 2D 화면의 얼굴 인상을 따르는 경우가 남는다.

### 8.3 오디오 반응성과 인과성

- audio controls가 사건 선택·시점·prompt 의미에는 연결됐지만 LTX 내부 motion을 raw audio latent로 제어하지 않는다.
- E237 한 곡만으로 사건 선택 정책의 일반성을 말할 수 없다.
- aligned, shifted, silent, fixed schedule 비교에 대한 사람의 지각 평가가 아직 없다.
- `음악과 잘 맞는다`는 현재 사용자 관찰이며 통계적 검증 결과가 아니다.

### 8.4 메시와 공간 일반화

- TheRock 하나에서만 전체 경로를 확인했다.
- 다른 topology, UV, 대칭성, 재질과 부위 구성을 가진 물체에서는 MSR와 사건 prompt를 다시 검증해야 한다.
- 고정 메시라는 원칙 때문에 실제 기하 변형은 만들지 않는다. 열린 갈비나 셔터는 표면 RGB의 깊이 단서다.

### 8.5 시간·UV 품질

- UV seam, 압축, 축소 해상도와 projector sampling에서 세부 사건이 약해질 수 있다.
- 완료 상태를 유지하는 구간에 exact duplicate frame이 생기는 것은 의도된 hold이지만, 지나치면 영상이 정지한 것처럼 느껴질 수 있다.
- 전면 source와 여러 관측 방향 사이의 정합이 완전한 multi-view generation은 아니다.

### 8.6 실제 프로젝션

- Unity 재생과 기존 DLT calibration 코드 연결은 완료했다.
- 실제 projector–실물 대응점 오차, 렌즈 왜곡, occlusion, brightness/color compensation은 아직 측정하지 않았다.
- 따라서 현재 결과를 `projection-ready`라고 부르면 안 된다.

### 8.7 agentic 범위

- 현재는 사람이 실험 목표와 후보 선택을 지시하고 스크립트가 제한된 탐색·검증을 수행한다.
- persistent state를 이용한 `observe → plan → act → evaluate → reflect → revise/stop` 전체 loop가 구현되지 않았다.
- 다수 모델을 호출했다는 이유만으로 fully agentic system이라고 주장하지 않는다.
